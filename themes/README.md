# Pacote com 100 temas CSS para Markdown

Este pacote contém **100 arquivos CSS**, **100 previews HTML**, o `DEMO.md` comum a todos os temas e o catálogo interativo `00-index.html`.

## O que mudou nesta versão

- Os 50 temas anteriores foram preservados.
- Foram adicionados 50 novos temas, numerados de 51 a 100.
- Os temas 51 a 80 usam fundo branco puro (`#FFFFFF`).
- `51-vertex-oxetechacademy.css` usa a paleta extraída do HTML TIC 64 enviado pelo usuário.
- Foram incluídos temas inspirados na identidade visual oficial Anthropic/Claude.
- Foram incluídas variações para e-mail, recibos, faturas, documentos jurídicos, QA, API, educação e impressão.
- O `00-index.html` permite clicar no tema e visualizá-lo ao lado, além de pesquisar e filtrar por categoria.

## Demonstração

Todos os previews continuam usando o mesmo `DEMO.md`, mantendo a comparação justa entre temas.
